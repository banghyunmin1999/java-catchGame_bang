# 몬스터 포획 게임 (java-catchGame 개인 프로젝트)

## 프로젝트 개요
이 프로젝트는 기존 그룹 프로젝트 'java-catchGame'을 기반으로 개인적으로 발전시킨 몬스터 포획 게임입니다. 포켓몬 게임에서 영감을 받아 만든 텍스트 기반 콘솔 게임으로, 다양한 지역을 탐험하며 몬스터를 만나고 포획하거나 싸울 수 있습니다.

## 새로운 기능
기존 그룹 프로젝트에서 다음과 같은 기능을 새롭게 추가하였습니다:

1.  **텍스트 박스 시스템**
    * 게임의 모든 출력을 텍스트 박스 안에 표시하여 가독성 향상
    * 한글 문자 인식 및 자동 줄바꿈 기능 추가
    * `TextBoxClass`를 새로 개발하여 일관된 UI 경험 제공

2.  **전투 시스템**
    * 야생 몬스터와의 전투 기능 구현
    * HP 시스템과 데미지 계산 로직 추가
    * 전투 결과에 따른 다양한 이벤트 처리

3.  **몬스터 관리 시스템**
    * 유저가 선택한 몬스터(`MonsterUser`)로 전투 가능
    * 보유한 몬스터 간 교체 기능 추가
    * 몬스터별 스탯(HP, 공격력) 시스템 도입

4.  **시각적 요소 개선**
    * 몬스터와 플레이어 몬스터의 ASCII 아트 출력
    * HP 바 시각화
    * 화면 레이아웃 개선

5.  **포획 시스템 개선**
    * 몬스터 HP에 따른 포획률 조정


## 게임 플레이 방법

### 메인 메뉴
1.  맵 선택하기
2.  몬스터 도감 보기
3.  몬스터 검색하기
4.  내 정보 보기
5.  게임 종료
6.  내 몬스터 교체

### 맵 탐색
* 하늘, 바다, 땅 중 원하는 맵을 선택하거나 랜덤으로 맵 선택 가능
* 각 맵마다 출현하는 몬스터가 다름
* 우주 맵은 랜덤 선택 시 일정 확률로 접근 가능한 히든 맵

### 몬스터 조우 시 행동
* 싸운다: 몬스터와 전투를 진행
* 포획한다: 몬스터를 포획 시도
* 도망간다: 전투에서 벗어남
* 내 몬스터 교체: 다른 몬스터로 교체

### 전투 시스템
* 전투 시 야생 몬스터의 공격력만큼 내 몬스터의 HP 감소, 내 몬스터의 공격력만큼 야생 몬스터의 HP감소
* 몬스터의 HP가 0이 되면 전투 종료
* 유저 몬스터의 HP가 0이 되면 게임 종료

### 도감 시스템
* 포획한 몬스터는 도감에 등록
* 등록된 몬스터의 정보 확인 가능
* 포획하지 않은 몬스터는 `???` 표시

## 클래스 구조

### 패키지 구조
* `catchGame`: 메인 클래스
* `catchGame.manage`: 게임 관리 클래스
* `catchGame.map`: 맵 관련 클래스
* `catchGame.monster`: 몬스터 관련 클래스
* `catchGame.user`: 유저 관련 클래스

### 주요 클래스
* `GameManager`: 전체 게임 진행 관리
* `TextBoxClass`: 텍스트 박스 출력 담당
* `MapExploring`: 맵 선택 및 탐색 기능
* `MonsterBase`: 모든 몬스터의 기본 클래스
* `MonsterUser`: 유저 몬스터 클래스
* `PrintImgClass`: 몬스터 이미지 출력 클래스
* `User`: 유저 행동 관리 클래스
* `PokeDexClass`: 포켓몬 도감 관리 클래스
* `Monster` : 0~10까지 각각 클래스 존재

## 기술적 특징

### 파일 구조
* 몬스터 이미지는 `.txt` 파일로 저장되어 게임 실행 시 불러옴
* 경로: `T:\github\java-catchGame_bang\src\catchGame\monster\`

### 몬스터 등장 확률
* 각 맵별로 몬스터 등장 확률이 다르게 설정

### HP 시스템
* 각 몬스터마다 최대 HP와 공격력 보유
* 전투 시 상호 공격으로 HP 감소
* HP 퍼센티지 계산 및 시각화

## 업데이트 내역
